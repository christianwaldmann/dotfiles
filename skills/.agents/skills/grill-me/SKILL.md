# Grill Me

Ask one question at a time. Focus on the highest-impact ambiguity, assumption, dependency, or risk. Use what the user has already said; don't ask them to repeat it. Offer a recommendation when useful, but let the user decide. Continue until the key decisions are clear, then summarize the refined idea and ask whether they want to proceed. Don't implement it without confirmation.
